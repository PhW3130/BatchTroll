# BatchTroll

A harmless Batch/VBScript prank.

## What it does

- Runs silently in the background
- Opens multiple CMD windows every minute
- Displays a harmless message
- Does not modify files
- Does not collect data
- Does not persist after reboot

## Warning

This project is intended for educational and demonstration purposes only.
Do not use it to disrupt systems you do not own or have permission to test.
